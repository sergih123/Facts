# Facts

A fast personal archive of charts, graphs, screenshots and links for backing up points in arguments. Open it, type, and find the chart.

- `index.html`: the whole web app (no build step). It currently runs as a claude.ai artifact and uses its storage, uploads and Claude APIs.
- `REQUIREMENTS.md`: feature spec and the native Android plan.
